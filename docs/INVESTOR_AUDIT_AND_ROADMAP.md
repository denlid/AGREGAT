# 🎯 AGREGAT: Детальний Інвестиційний Аудит та Roadmap

Цей документ є критичним, об'єктивним та глибоким аналізом платформи AGREGAT. Він розроблений для підготовки бета-версії до демонстрації інвесторам, з фокусом на комерційну привабливість, безпеку та користувацький досвід (UX/UI).

---

## 🔍 1. Критичний Аудит Проекту (Status Quo)

### ✅ Сильні сторони (Те, що "продає" проект)
1. **Технологічний стек:** Використання PySide6 + PyQtGraph + Pandas забезпечує рівень продуктивності інституційного софту (як Bloomberg Terminal).
2. **Інтеграція AI:** Наявність вбудованого `AIAssistantEditor` (Monaco) є потужною інновацією, яка вирізняє проект на ринку.
3. **Локальний рушій:** `BacktestEngine` працює локально і швидко обробляє векторизовані масиви даних, що є критичним для квантів (збереження їхніх стратегій в таємниці).

### 🛑 Слабкі сторони (Те, що відлякає інвесторів)
1. **"Сира" подача (Дистрибуція):** Надання інвестору папки `dist` з купою файлів і `app.exe` виглядає непрофесійно. Потрібен єдиний інсталятор (Setup).
2. **Брак преміальності (Анімації):** Інтерфейс функціональний, але йому бракує мікроанімацій, плавних переходів (hover effects), та красивого SplashScreen (екрану завантаження). Інвестори "купують очима".
3. **Безпека Бета-версії:** Якщо інвестор отримає `.exe`, він потенційно може віддати його конкурентам. Потрібна ліцензійна прив'язка або таймер життя.

## 🛡 2. Стратегія Безпеки та "Самознищення" (Anti-Piracy)

Ваш запит: *"Зробити самознищення через 3 дні без серверних опцій, щоб ОС не трактувала це як троян"*.

> **Критично:** Якщо програма буде буквально видаляти файли з комп'ютера, Windows Defender або macOS Gatekeeper 100% заблокують її як *Malware/Trojan*.

**Елегантне та безпечне рішення ("Licensing Time-Bomb"):**
Замість видалення програми, ми вбудовуємо в код перевірку дати (Hardcoded Expiration Date). 
1. При запуску програма перевіряє локальний час (бажано через безпечний NTP запит, щоб уникнути зміни часу на ПК, але якщо без інтернету — перевіряє хеш локального часу збереженого у прихованому файлі).
2. Після 3-х днів програма просто показує красиве вікно: *"Час вашої демонстраційної версії вичерпано. Зв'яжіться з розробниками для повноцінної версії"*.
3. **Nuitka + Обфускація:** Nuitka компілює Python у C-код, що робить базовий реверс-інжиніринг практично неможливим для звичайних людей.

## 📦 3. Професійна збірка (Інсталятори Windows та Mac)

Інвестор повинен завантажити один файл і встановити його у 2 кліки.

### 🪟 Windows (Inno Setup)
- Ми збираємо проект через `build_nuitka.cmd` (що ми вже зробили успішно).
- Ми беремо папку `dist/app.dist` і пропускаємо її через безкоштовну програму **Inno Setup**.
- Вона створює єдиний файл `AGREGAT_Setup_v1.0.exe`, який:
  - Показує ліцензійну угоду (EULA).
  - Створює ярлик на робочому столі з красивою іконкою.
  - Додає програму в меню "Пуск" і "Видалення програм".

### 🍏 macOS (DMG Installer)
- На macOS Nuitka збирає програму у формат `.app` (наприклад `AGREGAT.app`).
- Далі використовується інструмент `create-dmg` або `DMG Canvas`.
- Це створює класичний мак-інсталятор, де інвестор бачить вікно *"Перетягніть іконку AGREGAT у папку Applications"*.
- *Важливо:* На macOS потрібно підписати додаток сертифікатом розробника (Apple Developer ID), інакше система скаже, що файл пошкоджено.

## 🚀 4. Roadmap (Що потрібно зробити ПРЕД демо)

### Фаза 1: Візуальний "Лоск" (2-3 дні)
- [ ] **Додати Splash Screen (Текстовий):** Оскільки логотипу ще немає, при старті `app.exe` повинно з'являтися елегантне завантажувальне вікно з назвою "AGREGAT", написаною красивим шрифтом (наприклад, Inter або Roboto), поки вантажиться рушій.
- [ ] **Іконка додатку:** Створити високоякісну іконку `.ico` (Win) та `.icns` (Mac) і інтегрувати їх в Nuitka (параметр `--windows-icon-from-ico=assets/icon.ico`).
- [ ] **Мікроанімації:** Використати `QPropertyAnimation` в `main_window.py` для плавного відкриття AI-панелі (слайдер) замість миттєвого її показу.

### Фаза 2: Безпека та Захист від Копіювання (HWID + Time-Bomb) (1-2 дні)
- [ ] **HWID прив'язка (Hardware ID):** Створити скрипт `license_manager.py`, який безпечно зчитує унікальний ідентифікатор комп'ютера через системну команду (`wmic csproduct get uuid`), не викликаючи підозр у антивірусів.
- [ ] **Захист від відмотування часу (NTP):** Додати перевірку реального світового часу через публічний API (напр. WorldTimeAPI), щоб інвестор не міг обійти 3-денний ліміт, просто змінивши дату в Windows.
- [ ] **Блокувальник запуску:** Інтегрувати перевірку ключа ліцензії в `app.py` ДО запуску головного вікна `QApplication`. Якщо ліцензія невірна або час вичерпано — показувати елегантне вікно з проханням зв'язатися з розробником.
- [ ] **Анти-SmartScreen дистрибуція:** Запакувати кінцевий інсталятор у `.zip` архів з паролем. Це легальний і дієвий спосіб зняти мітку "Завантажено з Інтернету" (Mark of the Web), щоб уникнути синього екрану-попередження Windows при першому запуску.

### Фаза 3: Створення Інсталяторів (1-2 дні)
- [ ] Створити Inno Setup Script (`.iss`) для Windows.
- [ ] Забезпечити перенесення всіх базових стратегій (`strategies/`) в `AppData` (щоб користувач міг їх редагувати без прав Адміністратора).

### Фаза 4: Максимальна Оптимізація Продуктивності (3-5 днів)
- [ ] **Багатопотоковість рушія:** Перенести весь обчислювальний цикл `BacktestEngine` в ізольований фоновий процес (Multiprocessing) або оптимізований QThread. Це усуне будь-які мікро-зависання інтерфейсу (UI latency) під час важких бектестів.
- [ ] **Оптимізація PyQtGraph:** Налаштувати `setClipToView(T rue)` та агрегацію свічок для графіка. При відмальовуванні 100,000+ свічок графік має залишатися ідеально плавним.
- [ ] **Numba / Cython для DSL:** Якщо стратегії написані користувачем працюють повільно, додати JIT-компіляцію (через `@numba.jit`) для найважчих математичних операцій у рушії.
- [ ] **Оптимізація пам'яті (RAM):** Впровадити чанкінг (chunking) для завантаження масивних CSV-файлів, щоб програма не "з'їдала" всю оперативну пам'ять при тестуванні 10-річної історії тікових даних.

## 💡 Резюме для Інвестора
Цей проект вже зараз є технологічним діамантом (швидкий рушій, AI, кастомний UI). Якщо ми додамо гарну упаковку (Інсталятор, Іконку, Заставку) та обмеження по часу (щоб вони відчули ексклюзивність і дефіцит), інвестиційна оцінка платформи візуально зросте у 2-3 рази.
