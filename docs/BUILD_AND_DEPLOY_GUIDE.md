# 📦 AGREGAT — Повна інструкція: Збірка → Інсталятор → Інвестор

Ця інструкція описує весь процес від коду до моменту, коли інвестор працює з вашою платформою.

---

## 🔧 ЕТАП 1: Збірка додатку (Nuitka)

### Що потрібно:
- Python 3.13+ з усіма залежностями (`pip install -r requirements.txt`)
- Nuitka (`pip install nuitka`)
- Visual Studio Build Tools (C++ компілятор)
- Файл іконки `assets\icon.ico`

### Як зібрати:
1. Відкрийте термінал у папці проекту `agregat\`
2. Запустіть:
   ```
   build_nuitka.cmd
   ```
3. Дочекайтесь завершення (це займе 5-15 хвилин)
4. Результат: папка `dist\app.dist\` з файлом `app.exe` та всіма залежностями

> ⚠️ Якщо Windows Defender блокує процес збірки, тимчасово додайте папку `dist` у виключення Defender.

---

## 📀 ЕТАП 2: Створення інсталятора (Inno Setup)

### Що потрібно:
- Встановити безкоштовну програму **Inno Setup** з [jrsoftware.org](https://jrsoftware.org/isdl.php)

### Як створити інсталятор:
1. Відкрийте файл `agregat_installer.iss` подвійним кліком (він відкриється в Inno Setup)
2. Натисніть кнопку **▶ Compile** (або `Ctrl+F9`)
3. Дочекайтесь завершення
4. Результат: файл `dist\setup\AGREGAT_Beta_Installer.exe`

> Це один єдиний файл, який містить ВСЕ для установки програми.

---

## 📤 ЕТАП 3: Відправка інвестору

### Підготовка:
1. Візьміть файл `dist\setup\AGREGAT_Beta_Installer.exe`
2. Запакуйте його в **ZIP-архів з паролем** (через WinRAR або 7-Zip):
   - Натисніть правою кнопкою → **Додати до архіву**
   - Формат: **ZIP**
   - Поставте пароль, наприклад: `beta2026`
   - Назва архіву: `AGREGAT_Beta.zip`

> 💡 **Навіщо пароль?** Коли інвестор розархівує файл з паролем, Windows знімає мітку "Завантажено з Інтернету". Це запобігає появі синього вікна SmartScreen при першому запуску!

### Що надіслати інвестору (шаблон повідомлення):

```
Вітаю!

Надсилаю вам закриту бета-версію платформи AGREGAT для ознайомлення.

📎 У вкладенні: AGREGAT_Beta.zip
🔑 Пароль від архіву: beta2026

Інструкція:
1. Розпакуйте архів (введіть пароль beta2026)
2. Запустіть AGREGAT_Beta_Installer.exe
3. Після установки запустіть AGREGAT з робочого столу
4. Програма покаже ваш Hardware ID — скопіюйте його і надішліть мені
5. Я згенерую для вас ключ доступу протягом кількох хвилин

Примітка: Оскільки це закрита корпоративна бета-версія без 
публічного сертифіката, Windows може показати попередження. 
Натисніть "Детальніше" → "Виконати в будь-якому випадку".
Це стандартна практика для Pre-Seed етапу.
```

## 🔑 ЕТАП 4: Активація (Генерація ліцензії)

### Коли інвестор надіслав вам свій Hardware ID:

1. Відкрийте термінал у папці проекту `agregat\`
2. Запустіть генератор ліцензій:
   ```
   python engine/security/license_manager.py
   ```
3. Вставте HWID інвестора (наприклад: `8F2A34B190CD5EF7`)
4. Введіть кількість днів доступу (наприклад: `3`)
5. Скрипт видасть ліцензійний ключ — довгий рядок символів

### Що надіслати інвестору:

```
Ваш ключ активації:

eyJoIjoiOEYyQTM0QjE5MENENUVGNyIsImUiOiIyMDI2LTA1LT...

Вставте його у поле "Ліцензійний ключ" у вікні активації
програми і натисніть "Активувати". Усе!

Доступ відкрито на 3 дні.
```

> Інвестору НЕ потрібно створювати жодних файлів вручну! Він просто копіює ключ → вставляє у вікно програми → натискає "Активувати" → готово!

## ❓ FAQ

**Q: Що буде через 3 дні?**
A: Програма перевіряє час через інтернет. Після закінчення терміну інвестор побачить повідомлення "Час демонстраційної версії вичерпано" і програма закриється. Йому потрібно буде знову зв'язатися з вами для нового ключа.

**Q: Що якщо інвестор перевів годинник назад?**
A: Програма перевіряє час через публічний сервер WorldTimeAPI. Якщо інтернету немає — використовує локальний час, але також зберігає дату останнього запуску для додаткової перевірки.

**Q: Чи може інвестор передати програму іншій людині?**
A: Ні. Ліцензія прив'язана до серійного номера материнської плати (HWID). На іншому комп'ютері буде інший HWID, і ключ не спрацює.

**Q: Чи може хакер зламати захист?**
A: Nuitka компілює Python у машинний C-код. Код захищений HMAC-SHA256 підписом, динамічною генерацією ключа, перевіркою цілісності, анти-дебагером, та функціями-приманками. Це робить злам надзвичайно складним і дорогим.

**Q: Чи буде Windows Defender сваритись?**
A: Ми спеціально уникаємо всіх "тригерів" антивірусу: не шифруємо файли, не видаляємо нічого, не використовуємо пакувальники. Програма встановлюється в `AppData` (як Chrome/VS Code), що не вимагає прав адміністратора.
