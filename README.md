# AGREGAT Platform v7.78

**AGREGAT** (Algorithmic Graphical Reviewer Engine Genius Analytics Tester) — це інституційна платформа для бектестингу, кількісного аналізу та розробки торгових алгоритмів. 

## 🌟 Основні можливості

- 📊 **Просунутий графічний інтерфейс**: Побудований на PySide6 (Qt) та PyQtGraph. Високопродуктивний рендеринг графіків без затримок.
- 🤖 **Вбудований AI-Асистент**: Пишіть та редагуйте стратегії безпосередньо в платформі за допомогою штучного інтелекту, аналізуйте графіки та отримуйте пояснення коду.
- ⚙️ **Власний Бектест-Рушій**: Швидкий, векторизований рушій, здатний симулювати торги на великих масивах даних з підтримкою крокового відтворення (Replay Mode).
- 📈 **Кількісний Аналіз**: Детальна статистика (Sharpe, Drawdown, Win Rate), аналітика розподілу прибутків та звітність рівня хедж-фондів.
- 📝 **Редактор Стратегій**: Вбудований редактор коду (Monaco Editor) з підсвічуванням синтаксису для швидкого прототипування торгових логік на Python.

## 🚀 Встановлення та Запуск

### Запуск з вихідного коду
Для запуску платформи з вихідного коду переконайтеся, що у вас встановлено Python 3.10+.

1. Клонуйте репозиторій або розпакуйте архів.
2. Встановіть залежності:
   ```bash
   pip install -r requirements.txt
   ```
3. Запустіть застосунок:
   ```bash
   python app.py
   ```

### Зібрана версія (Standalone)
Якщо у вас є скомпільована версія `AGREGAT`, просто запустіть `app.exe` у папці `dist/app.dist`. Усі необхідні компоненти вже включені всередину!

## 📖 Як користуватися

1. **Завантаження Даних**: Натисніть кнопку відкриття файлу та виберіть CSV файл з історичними котируваннями (формату OHLCV).
2. **Написання Стратегії**: Перейдіть на вкладку "Editor" або "AI Assistant", щоб написати логіку вашої стратегії.
3. **Запуск Бектесту**: Натисніть кнопку "Play" або пробіл для запуску візуальної симуляції.
4. **Аналіз Результатів**: Після завершення симуляції перейдіть на вкладки "Stats", "Analytics" або "Trades" для огляду продуктивності стратегії.

## ⌨️ Гарячі клавіші

- `Пробіл` — Запустити/Зупинити симуляцію (Replay)
- `Shift + ->` — Крок вперед (наступна свічка)
- `Shift + <-` — Крок назад (попередня свічка)
- `Ctrl + = / Ctrl + -` — Зум графіку
- `Ctrl + S` — Зберегти стратегію (у вкладці Editor) або зберегти сесію
- `Ctrl + Alt + R` — Швидко докрутити симуляцію до кінця

## 🛠 Збірка (Для розробників)

Для збірки проекту в один незалежний `.exe` файл використовується Nuitka. Ми створили зручний скрипт:

1. Запустіть файл `build_nuitka.cmd`.
2. Зачекайте завершення збірки (це може зайняти 5-15 хвилин).
3. Готова програма з'явиться в папці `dist/app.dist`.
