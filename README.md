# AGREGAT Backtesting Platform

**AGREGAT** — це високопродуктивна, інституційна платформа для розробки, тестування та аналізу алгоритмічних торгових стратегій. Вона поєднує в собі точність візуального покрокового аналізу (Bar-by-Bar) з блискавичною швидкістю векторизованих обчислень (Fast Quant) та глибоким статистичним аналізом.

## 🌟 Ключові Можливості (Огляд Функціоналу)

### 1. Двоядерна Архітектура (Dual-Engine)
Платформа підтримує два режими виконання, які забезпечують ідеальний баланс між глибиною розробки та швидкістю тестування:
- **Visual Mode (Bar-by-Bar):** Покрокове виконання стратегії. Ви бачите кожну свічку, кожен індикатор і кожен маркер угоди в реальному часі. Ідеально для дебагу та візуального розуміння логіки.
- **Fast Quant Mode (Vectorized):** Оптимізований режим, у якому важкі цикли Python замінені на швидкі векторизовані операції NumPy/Pandas. Дозволяє прогнати сотні тисяч свічок за секунди для швидкого отримання статистичних даних.

### 2. Реалістична Емуляція Виконання (Execution Model)
AGREGAT імітує реальні ринкові умови, не залишаючи шансу на випадкову "підгонку" (curve-fitting):
- **Спреди та Проковзування (Slippage):** Шорт-позиції відкриваються та закриваються по ціні *Ask*, а Лонг — по *Bid*.
- **Жорсткий Ризик-Менеджмент:** Алгоритми обчислення розміру лоту (`calculate_lot`) враховують абсолютні ліміти брокера (`absolute_max_lots`) та ризик на угоду.
- **Точна обробка SL/TP:** Консервативний підхід вирішення колізій в межах однієї свічки: якщо ціна торкнулась і SL, і TP, система завжди обирає найгірший варіант (Stop Loss).

### 3. Багатоекранний Аналіз (Dual View)
- Вкладка **Chart** дозволяє увімкнути режим "Dual View", створюючи незалежний розділений екран (Splitter).
- Кожен екран має власні налаштування таймфреймів та типів графіків (Свічки, Лінії, Heikin Ashi), що дозволяє аналізувати мульти-таймфреймові стратегії одночасно (наприклад, 1H зліва і 5m справа).

### 4. Тотальний Квантовий Аналіз (Analytics & Quant Tabs)
Після завершення прогону AGREGAT надає аналітику, яка зазвичай зустрічається лише в комерційному ПЗ:
- **Drawdown Episodes:** Точна таблиця всіх періодів просадки з їхньою глибиною та тривалістю.
- **MAE / MFE Аналіз:** Scatter-графіки максимального несприятливого (MAE) та сприятливого (MFE) відхилення ціни для оцінки того, наскільки ефективними є ваші Stop Loss та Take Profit.
- **Monte Carlo Симуляції:** Оцінка вірогідності "розорення" (Risk of Ruin) через перестановку угод.
- **Heatmaps:** Теплові карти прибутку (Година × День тижня, Місяць × Рік) для виявлення сезонності в роботі стратегії.
- **R-Multiples:** Аналіз математичного очікування у вигляді відношення ризику до прибутку.

### 5. Журнал Угод (Trades Tab)
Інтерактивна таблиця всіх угод з можливістю сортування, фільтрації (за напрямком, PnL, датою) та миттєвим пошуком. Підтримує експорт у CSV та Excel для зовнішнього аналізу.

### 6. Управління Налаштуваннями та Темами
- **Premium Themes:** Темна та Світла теми з ретельно підібраними кольорами (через централізований `theme.py`), які працюють навіть на рівні графіків PyQtGraph.
- **Asset Configs:** Можливість додавати кастомні інструменти (Крипта, Форекс, Індекси) з їхніми унікальними значеннями пунктів (pip value) та розмірами контрактів.

## ⚙️ Встановлення для Розробників

AGREGAT використовує `pyproject.toml` (PEP 621) і стандартний бекенд
`setuptools`. Рекомендований шлях встановлення:

```bash
git clone https://github.com/alephxau/agregatic.git
cd agregatic
python -m pip install --upgrade pip
pip install -e ".[dev]"
```

Запуск інтерфейсу:

```bash
agregat-gui          # консольний скрипт із pyproject.toml
# або
python app.py        # прямий запуск (без встановлення)
```

### Pre-commit хуки

Для уніфікованого стилю коду налаштовано `pre-commit` з `ruff`,
`black` та базовими хуками. Встановіть один раз після клону:

```bash
pre-commit install
pre-commit run --all-files   # перевірити/відформатувати весь репо
```

Ті самі перевірки запускаються в CI на кожен PR (див.
`.github/workflows/ci.yml`).

### Тести / лінтінг локально

```bash
pytest -q                 # 402+ тести
ruff check .              # лінтінг
ruff format --check .     # перевірка форматування
mypy engine               # тайпчек ядра
python -m bench.run_all   # перформанс-бейслайн (~3 хв на 200к барів)
```

## 🚀 Гайд Користувача (Як Користуватися)

### Крок 1. Завантаження Даних та Стратегії
1. На панелі меню виберіть **File -> Load Data...** і завантажте `.csv` файл з історичними котируваннями (формат: `time, open, high, low, close, volume`).
2. Виберіть **File -> Load Strategy...** і вкажіть `.py` файл з вашою стратегією (вона має наслідувати `Strategy`).

### Крок 2. Налаштування Умов (Toolbar)
1. **Інструмент (Asset):** Виберіть актив з випадаючого списку (напр. `DE40`). Якщо вашого активу немає, натисніть `+`, щоб додати його параметри.
2. **Дати (Range):** Якщо потрібно протестувати стратегію лише за певний період (напр. тільки 2023 рік), натисніть **📅 Range** і вкажіть дати.
3. **Таймфрейм:** Виберіть базовий таймфрейм для відображення графіка.

### Крок 3. Запуск Бектесту
- **▶ Play:** Запускає візуальний покроковий прогін. Ви можете регулювати швидкість повзунком поруч.
- **⏩ RUN:** Миттєвий запуск до кінця (Fast Run). Якщо ваша стратегія підтримує векторний режим, програма запитає вас, чи хочете ви використати **Vectorized Quant** для максимальної швидкості.

### Крок 4. Аналіз Результатів
- **Stats Tab:** Перегляньте загальні показники: Win Rate, Profit Factor, Sharpe Ratio, Max Drawdown.
- **Chart Tab:** Прокрутіть графік назад, щоб побачити маркери угод (зелені/червоні трикутники).
- **Quant / Analytics Tabs:** Дослідіть теплові карти, MAE/MFE та оцініть, наскільки стабільною є стратегія.
- **File -> Save Session:** Збережіть результати у формат `.agbk`, щоб пізніше порівняти цю стратегію з іншими (вкладка *Compare*).

## 🛠 Архітектура Проекту

- **`app.py`:** Точка входу. Ініціалізує PyQt6, застосовує High-DPI налаштування та запускає головне вікно.
- **`engine/`:** Ядро платформи.
  - `backtest_engine.py`: Керує циклом симуляції, станом угод та оцінкою Equity.
  - `vectorized_engine.py`: Швидкий режим бектесту без Python `for`-циклів.
  - `execution.py`: Математика брокера (комісії, спреди).
  - `context.py`: API, з яким працюють користувацькі стратегії.
- **`gui/`:** Інтерфейс користувача.
  - `main_window.py`: Каркас, Toolbar та інтеграція вкладок.
  - `theme.py`: Менеджер кольорів (Design Tokens), що забезпечує зміну тем без артефактів.
  - Вкладки (`chart_tab.py`, `stats_tab.py`, `quant_tab.py`): Віджети для візуалізації різних аспектів даних.
